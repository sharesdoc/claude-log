# /his — 任务历史回看

## 参数

- `$ARGUMENTS` 是用户传入的天数（可能为空）。请按以下规则解析为正整数 `N`：
  - 空 / 缺省 → `N = 1`
  - `1` → 今天
  - `2` → 今天 + 昨天
  - `N`（正整数）→ 最近 N 天
  - 非正整数或非数字 → 提示"参数应为正整数，使用默认值 1"并继续以 1 处理
  - `N > 30` → 提示"范围较大，截断到 30"并以 30 处理

## 数据源定位

历史归档不再放在项目本地,而是位于全局档案路径,以 cwd 的 sha1 哈希定位。
**必须**用如下 Bash 计算(macOS 默认无 `sha1sum`,用 `shasum -a 1` 兜底):

```bash
hash=$(printf '%s' "$PWD" \
  | { command -v sha1sum >/dev/null 2>&1 && sha1sum || shasum -a 1; } \
  | awk '{print $1}')
hist="$HOME/.cai/projects/$hash/history.md"
```

## 执行步骤

按以下流程执行，**不要二次摘要内容**——用户要的就是原话回放：

1. **定位文件**：用上述 Bash 计算 `$hist` 并 `Read` 它。若不存在,回答:

   > 当前项目尚无任务历史（`$hist` 不存在）。它将在你首次说「任务完成」后由 claude-log 插件自动生成。

   然后结束。

2. **计算日期窗口**：取本机今天日期 `YYYY-MM-DD`，向前展开 N-1 天，得到日期前缀集合。

3. **读取并过滤**：按 `## YYYY-MM-DD-Txxx` 段头切分；保留段头日期落在窗口内的条目。

4. **倒序输出**：按 `日期 desc, Txxx desc` 排序。

5. **输出格式**：

   ```text
   📌 最近 N 天任务历史（共 X 条）

   ## YYYY-MM-DD-T003：标题
   - 需求/问题：…（原文）
   - 决策/方案：…（原文）
   - 验收/总结：…（原文）
   - 关联标准文件：…（原文）

   ## YYYY-MM-DD-T002：标题
   …
   ```

   末尾追加：`📊 今天 X 条 / 昨天 Y 条 / ...`（仅显示窗口内非零的日期）。

## 边界场景

- **窗口内无条目** → 回答 `📭 最近 N 天（YYYY-MM-DD ~ YYYY-MM-DD）暂无任务归档。`，不要硬凑。
- **格式不规范的条目**（缺 `Txxx` 等）→ 跳过，末尾追加 `⚠️ 跳过 K 条格式不符的条目`。

## 反模式

- ❌ 不要"重新解读"任务、不要给元评论。
- ❌ 不要修改 `$hist`，只读。
- ❌ 不要跨项目读取其它 hash 目录下的 history.md。
