# /his — 任务历史回看

## 触发与参数解析

用户调用形式：

- `/his`     → N = 1（仅今天）
- `/his 1`   → N = 1（仅今天）
- `/his 2`   → N = 2（今天 + 昨天）
- `/his 3`   → N = 3（今天 + 昨天 + 前天）
- `/his N`   → 最近 N 天

**参数校验**：

- 若用户给的不是正整数（如 `0`、`-1`、`abc`），明确告知"参数应为正整数，使用默认值 1"并继续。
- 若 N > 30，提示"范围较大，将仅显示前 30 天结果"并截断到 30。

## 数据源定位

任务条目位于 **以当前项目 cwd 的 sha1 哈希命名的全局档案路径**。
**必须**用如下 Bash 计算(macOS 默认无 `sha1sum`,用 `shasum -a 1` 兜底):

```bash
hash=$(printf '%s' "$PWD" \
  | { command -v sha1sum >/dev/null 2>&1 && sha1sum || shasum -a 1; } \
  | awk '{print $1}')
hist="$HOME/.cai/projects/$hash/history.md"
```

由 `claude-log` 插件的 Stop hook 在用户说"任务完成"时自动追加,格式:

```text
## YYYY-MM-DD-Txxx：标题
- **需求/问题**：...
- **决策/方案**：...
- **验收/总结**：...
- **关联标准文件**：...
```

## 执行步骤

1. **定位文件**:用上述 Bash 计算 `$hist`。若不存在,回答"当前项目尚无任务历史(`$hist` 不存在)。它将在你首次说『任务完成』后由插件自动生成。"并结束。

2. **计算日期窗口**:取本机今天日期 `YYYY-MM-DD`,向前展开 N-1 天,得到一个日期前缀集合 `{T0, T-1, ..., T-(N-1)}`。

3. **读取并过滤**:用 `Read` 读取 `$hist`,按 `## YYYY-MM-DD-Txxx` 段头切分,保留段头日期落在窗口内的条目。

4. **倒序输出**:按 `时间 desc, Txxx desc` 排列(最新的在最前)。

5. **输出格式**:

   ```text
   📌 最近 N 天任务历史（共 X 条）

   ## YYYY-MM-DD-T003：标题
   - 需求/问题：……
   - 决策/方案：……
   - 验收/总结：……
   - 关联标准文件：……

   ## YYYY-MM-DD-T002：标题
   ……
   ```

   - 每条**完整保留**四段原文（不要二次摘要，用户要的就是原话）。
   - 段间空一行，方便扫读。
   - 末尾给一行汇总：`📊 今天 X 条 / 昨天 Y 条 / 前天 Z 条 ...`（仅显示窗口内非零的日期）。

## 边界场景

- **文件为空**或**窗口内无条目**：回答 "📭 最近 N 天（YYYY-MM-DD ~ YYYY-MM-DD）暂无任务归档。" 不要硬凑。
- **格式不规范的条目**（比如段头缺少 `Txxx`）：跳过并最末追加一行 `⚠️ 跳过 K 条格式不符的条目`。
- **超大文件**（>500 KB）：仍按需读取，但提醒用户考虑归档老条目到同目录的 `history.archive.md`。

## 反模式（不要做）

- ❌ 不要"重新解读"任务，不要给"我观察到 X 趋势"之类的元评论 —— 用户要的是事实回放。
- ❌ 不要跨项目读取其它 hash 目录下的 history.md。
- ❌ 不要修改 `$hist`，只读。
- ❌ 不要在没有任何条目时编造"暂无任务但你最近写了 X 代码"——直接说没有就行。
